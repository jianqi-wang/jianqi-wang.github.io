# 💻 Featured Project
## Credit Risk Modeling with Python
Developed an end-to-end **credit risk modeling framework in Python** using Lending Club data (~890,000 observations), covering data preprocessing, **Probability of Default (PD), Loss Given Default (LGD), Exposure at Default (EAD), and Expected Loss (EL)** estimation.
Applied **logistic regression and statistical modeling** for model development and evaluated predictive performance using **ROC, Kolmogorov–Smirnov (KS) statistics, and confusion matrices**.

**Tools:** Python · pandas · NumPy · scikit-learn · statsmodels · matplotlib · seaborn

**[View Project on GitHub](https://github.com/jianqi-wang/Credit-Risk-Modeling)**
